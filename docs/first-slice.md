# 첫 구현: 아티팩트와 SBOM 연결

## 목표

정확한 아티팩트 digest에 SBOM 원본과 Dependency-Track 프로젝트/버전을 연결합니다. 첫 단계는 로컬 Dependency-Track 구성입니다. 다음 단계에서 공개 또는 합성 아티팩트 하나로 연결과 분석을 검증합니다.

## 완료 기준

1. Dependency-Track UI/API와 영속 DB가 로컬에서 기동한다.
2. 아티팩트 위치와 digest, SBOM sha256 및 생성 도구 버전을 기록한다.
3. CycloneDX SBOM을 프로젝트/버전에 업로드하고 구성요소를 확인한다.
4. 업로드 접수와 분석 완료를 구분하고 분석 시점을 기록한다.
5. 같은 아티팩트/BOM 재전송과 다른 버전 등록의 동작을 확인한다.
6. 대상 아티팩트에서 SBOM 원본 및 분석 결과를 추적할 수 있다.

## 비목표

릴리스 승인, 배포 자동화, 전체 도구 통합, 별도 아티팩트 레지스트리 개발. Grype 비교는 연결 검증 후 후속 실험으로 둡니다.
