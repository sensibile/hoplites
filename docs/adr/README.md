# Architecture Decision Records

프로젝트의 합의된 기술·데이터 처리 결정을 누적합니다. 문서는 `NNNN-short-title.md` 형식으로 번호를 부여하고 상태, 날짜, 배경, 결정, 대안, 영향, 검증 근거를 기록합니다.

수정으로 과거 결정을 숨기지 않습니다. 결정이 바뀌면 새 ADR을 추가하고 이전 문서에 대체 문서를 연결합니다. ADR은 구현 완료 증거와 별개이며 미구현 사항을 명시합니다.
