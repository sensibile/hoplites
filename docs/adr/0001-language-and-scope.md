# 0001 언어와 단계별 범위

- 상태: Accepted
- 날짜: 2026-10-03

## 배경

배포 관리까지 확장할 장기 목표와 현재 실험 범위를 혼동하지 않도록 기준이 필요하다.

## 결정

웹앱·서버는 Elixir, 복잡한 CLI는 Rust, 스크립트로 충분한 작업은 Python을 사용한다. 최종 목표는 보안 및 라이선스 이행 근거를 연결하는 배포 관리 시스템이다. 현재는 아티팩트-SBOM 연결, 보강과 정규화 실험에 집중한다.

## 대안과 영향

처음부터 전체 플랫폼과 여러 서비스를 구축하는 접근은 보류한다. 언어 기준은 합의됐으나 웹앱과 Rust CLI는 미구현이다.

## 근거
