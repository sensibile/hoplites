# 0002 원본 보존과 패키지 중심 BOM

- 상태: Accepted
- 날짜: 2026-10-03

## 배경

Syft의 파일 증거가 DT에서 독립 의존성처럼 표시되어 CRT 및 설정 파일과 패키지가 혼재했다.

## 결정

원본 Syft BOM과 보강본을 보존한다. DT용 정규화본에서는 해시 및 단일 소유 관계가 확인되고 BOM에 패키지가 존재하는 파일만 통합한다. 파일별 원본 정보와 소유 근거는 sidecar에 보존한다. 참조는 소유 패키지로 재연결하고 충돌·미확인 파일은 유지한다.

## 대안과 영향

모든 파일 삭제는 증거 손실로 거부한다. 파일별 패키지 라이선스 추정 보강은 보존하되 DT 기본 목록은 패키지 중심으로 사용한다. Elixir ARM64 실험에서 264개 통합, 36개 유지, 서버 확인 완료. 파일-level 확정 라이선스나 의무 면제가 아니다.
