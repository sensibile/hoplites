# ADR 0010: 새 이미지 처리의 작업 계약

- 상태: 채택
- 날짜: 2026-10-03

## 배경

새 Python slim 작업에서 기존 구현과 실험 기준을 충분히 적용하지 않은 채 DT 업로드로 작업을 종료했다. Trivy 비교, 미해결 보강과 DT 검증 실패 해결이 남았다. 기존 문서의 선택적 비교 표현과 초기 단계 설명도 현재 작업 기준을 명확히 전달하지 못했다.

## 결정

새 이미지·버전 작업은 최신 구현 확인, 기존 어댑터·규칙 적용/확장, Syft·Trivy 교차검증, 표준 필드 보강, 제출 증적, DT 검증을 수행한다. 상세 계약은 [작업 지침](../image-processing-workflow.md)에 둔다. AGENTS.md에서 시작 전 열람과 필수 완료 기준을 요구한다. BOSS가 좁은 단계만 요청한 경우 수행 범위와 남은 단계를 명시한다.

## 대안과 영향

단순 업로드 후 경고만 남기는 방식은 조사·보강·검증 목표를 달성하지 못하므로 완료 기준으로 채택하지 않는다. 미해결을 숨기거나 억지로 확정하는 방식도 채택하지 않는다. 교차검증 비용이 증가하지만 새 이미지에서 축적한 차이를 재사용 가능한 규칙과 근거로 남긴다.

## 검증과 구현 경계

Python slim의 저장된 산출물과 작업 기록, 기존 비교·보강 문서를 대조해 지침을 작성했다. CLI의 `--trivy`는 여전히 선택 옵션이며 자동 항목 비교/정책 gate는 구현하지 않았다. 이 결정은 작업 지침으로 적용한다. 기존 Python slim의 재처리와 DT 업데이트는 이 문서 변경의 완료 증거가 아니다.

작업 검증도 종류별로 구분한다. 문서 전용 변경은 내용·링크·diff 검사로 확인하고 보안·독립 리뷰를 필수로 실행하지 않는다. 실행 코드·설정 변경에는 기존 gate를 유지한다. 현재 훅의 문서 예외는 자동화하지 않았으며 AGENTS.md의 해당 push에 한정한 절차로 적용한다.
