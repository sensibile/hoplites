# 0006 내부 코드 라이선스 매핑과 부모 식 보강

- 상태: 적용
- 날짜: 2026-10-03

## 배경

소스 빌드 설치 런타임의 주 라이선스만으로는 함께 배포되는 모듈·네이티브 코드의 별도 선언을 표현하지 못합니다.

## 결정

정확한 소스 아카이브 해시와 설치 파일·버전 근거를 결합하고, 확인된 원문 일치와 컴파일/네이티브 포함 추정을 구분합니다. 검토한 규칙은 SQL 마이그레이션으로 보존합니다. 부모 라이선스 필드에 포함 코드 식을 AND 집합으로 표현하되 OR 선택지·WITH 예외·LicenseRef를 보존하며, 코드별 상세 매핑은 증적으로 제공합니다.

업스트림 NOASSERTION도 생략하지 않습니다. 설치 코드에 연결되면 미확정 LicenseRef 표식과 명시적 상태를 표준 식·보고서·속성에 남깁니다. 표식은 확인된 라이선스 또는 이행 완료를 뜻하지 않습니다.

## 대안과 영향

Apache-2.0 하나만 유지하면 내부 선언을 가립니다. 모든 소스 라이선스를 무조건 추가하면 테스트·문서·미포함 코드까지 포함할 수 있습니다. 하위 구성요소로 쪼개는 대안은 추후 내부 취약점 추적에서 유용하지만 현재 패키지 단위 화면에서는 부모와 중복 집계할 수 있습니다. 이번 단계는 식과 증적으로 실제 포함 근거를 제공하며 미확정을 보존합니다.
