# 0005 설정·인벤토리 파일과 OS 라이선스 범위

- 상태: 적용
- 날짜: 2026-10-03

## 배경

패키지·런타임 정규화 후 hosts/hostname/APK DB가 독립 파일 항목으로 남았고, Alpine OS의 라이선스 필드는 비어 있었습니다. 파일 및 집합 항목을 별도 코드 패키지처럼 취급하면 라이선스 보강의 단위가 불명확해집니다.

## 결정

원본 이미지 레이어의 해시와 설정·DB 형식을 확인한 관리용 파일은 소프트웨어 목록에서 분리하고, 구성요소 원문·내용·해시·레이어를 증적으로 보존합니다. 이미지 파일은 제거하지 않습니다. 충돌·미검증 참조는 임의 삭제하지 않습니다.

OS 항목은 식별·버전을 유지합니다. 배포판 집합의 라이선스를 한 값으로 추측하지 않고 평가 범위를 명시하며, 포함 패키지·직접 설치 런타임의 실제 라이선스 보강 및 후속 의무 관리를 계속합니다.

## 대안과 영향

모든 파일을 DT에 유지하면 소프트웨어 의무 관리 단위와 설정 증거가 혼재합니다. OS 항목에 단일 라이선스를 넣으면 포함 소프트웨어의 다른 라이선스를 가릴 수 있습니다. 분리 후 제출·검토자는 증적에서 제외 근거를 추적할 수 있으며, OS 항목의 빈 라이선스는 명시한 집합 처리 범위와 함께 해석해야 합니다.

## 검증 근거

[실험 기록](../platform-metadata-normalization.md). 파일 3개 분리, Alpine 3.24.2 유지, 28개 DT 반영 및 소프트웨어 27개의 라이선스 보존을 API로 확인했습니다. 테스트 24개 통과. 제3자 적용 관계와 실제 의무 이행은 이 결정의 완료 범위에 포함되지 않습니다.
