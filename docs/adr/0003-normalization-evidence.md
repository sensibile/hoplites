# 0003 정규화 증적 묶음

- 상태: Accepted
- 날짜: 2026-10-03

## 배경

원본과 정규화본을 제출할 때 어떤 항목이 왜 개별 목록에서 빠졌는지 추적할 자료가 필요하다. 제출처의 구체적 요구 형식은 아직 확인하지 않았다.

## 결정

원본·정규화 BOM, 소유 보고서, 파일 통합 JSON, APK DB, CSV·HTML 보고서와 SHA-256 manifest를 묶는다. 입력 및 출력 해시, 규칙 버전, 이미지 식별자, 생성 도구, 증적 생성 시각과 변환 재실행 검증을 기록한다. 파일은 납품물에서 제거된 것이 아니라 소유 패키지에 통합된 것으로 표현한다.

## 대안과 영향

정규화본만 제공하면 재검증이 어려워 채택하지 않는다. manifest는 무결성 확인용이며 전자서명이나 외부 인증은 아니다. rootfs는 용량 때문에 묶음 밖에 보관하고 해시를 기록한다. PDF와 서명·외부 제출은 아직 구현하지 않았다.
