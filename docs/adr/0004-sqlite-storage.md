# 0004 SQLite 마이그레이션과 데이터 보존

- 상태: Accepted
- 날짜: 2026-10-03

## 배경

반복 이미지 실험에서 근거 재사용과 실행 이력 검색이 필요하다.

## 결정

SQLite 스키마 변경은 번호가 있는 SQL 마이그레이션으로 Git에 누적하고 적용된 파일은 수정하지 않는다. 실제 DB 파일은 Git에서 제외한다. 이미지별 수집 기록은 런타임 데이터이며 마이그레이션에 넣지 않는다. 원본 파일과 JSON export/import를 통해 이동 및 백업할 수 있도록 한다.

## 대안과 영향

대안은 JSON만 사용하거나 별도 서버 DB를 운영하는 방식이다. 현 단계는 SQLite를 선택했으나 스키마·runner·export/import는 아직 미구현이며 이 ADR은 구현 완료를 의미하지 않는다.
